Executive Summary

Top 5 announcements that matter

1. Gemini Spark ★

24/7 personal agent on dedicated Google Cloud VMs (not on-device). Runs while phone is off. Integrated with Gmail/Docs/Slides + Canva, OpenTable, Instacart. Beta to AI Ultra US, week of May 26.

2. Antigravity 2.0 + CLI + SDK

Agent-first dev platform replacing Gemini CLI (sunset June 18, 2026). Managed Agents API spins isolated Linux envs per call. Frontal hit on Cursor, Claude Code, Copilot, Devin.

3. Play Store "AI store" overhaul

Play Shorts (TikTok-style discovery feed), Ask Play (conversational finder), Engage SDK surfacing apps inside the Gemini app, Gemini auto-listings. App discovery detached from the list view.

4. Gemini 3.5 Flash GA + Omni

3.5 Flash beats last year's 3.1 Pro at $1.50 / $9.00 per M tokens (~25% cheaper). Omni = one multimodal backbone (text/image/audio/video in → video out, ~10s clips, physics-aware).

5. Android XR "Intelligent Eyewear" (context only — hardware out of scope)

Samsung + Warby Parker + Gentle Monster audio glasses Fall 2026; Gucci/Kering joining; iPhone-compatible. Mentioned because the Astra perception layer is the AI substrate that ships with them.

The thesis in one sentence

What Google is actually building

Google is collapsing search, apps, the OS, and the browser into a single agentic substrate (Gemini) that interacts with users by intent, not by app icon — and is rebuilding every distribution surface (Search, Play, Chrome, Workspace, Android, Glasses) so the agent, not the user, becomes the primary client.

Deep Dive

Gemini Spark — the architecture is the news

What's actually shipping

  • Persistent compute per user — dedicated VM, not on-demand inference
  • Persistent context, persistent agent identity
  • Runs while phone is off — server-side execution
  • Recurring tasks + custom sub-agents
  • Hand-curated integrations: Canva, OpenTable, Instacart

What this signals

  • Ongoing infra cost per Ultra subscriber — only works if agent retention drives stickiness
  • Price cut $249 → $99 means either inference costs collapsed or $249 was choking adoption
  • Prices ChatGPT Pro ($200) and Claude Max ($200) awkwardly
  • Server-side execution = no on-device privacy story
  • No public Action SDK for 3rd-party devs to plug in

Two white-space arrows for a startup

1. Privacy-first / on-device agent for regulated industries that cannot route through Google VMs.
2. Spark Action SDK middleware — write once, ship to Spark + Apple Intelligence + Copilot Actions.

Play Store · Billing, monetization, sideload

Fee restructuring (post-Epic)

  • Standard: 20% existing installs / 15% new installs
  • Subscriptions: 10%
  • Cosmetic items: 9% · Gameplay-affecting: 20%
  • +5% processing if using Play Billing (US/UK/EU)
  • Fee applies regardless of billing method
  • Apple's 30/15 now looks predatory by contrast

Play Billing Library 9.0

  • Released May 19, 2026
  • In-app messaging for opt-in price increases
  • Blocked returns: BILLING_UNAVAILABLE
  • getLinkUri now @Nullable
  • Targets SDK 35
  • Single-sprint migration from v8

Alt billing + external links

  • Permitted in US since Jan 28, 2026 post-Epic settlement
  • Devs can show side-by-side pricing
  • Agentic Catalog Management: bulk SKU import + price changes + regional pricing recs

Sideloading / Dev Verification

  • Sept 2026: mandatory dev verification (via Android Developer Console) to sideload in BR, ID, SG, TH. Global rollout follows.
  • Registered Third-Party Stores: alt stores meeting safety/quality benchmarks get one-click install + fewer warnings — built into Android 17 (likely QPR2, Dec 2026)
  • EU excluded (DMA constraints)

Opinionated assessment

White space — where Google is not investing

1. Privacy-first agents

Spark runs on Google Cloud VMs. No consumer "never leaves device" story.

2. Voice for developers

Gmail Live got voice; Antigravity is text/CLI.

3. Vertical app stores

No Play-equivalent for kids, education, healthcare, enterprise-internal.

4. App-store-as-a-service

No itch.io-for-mobile for indies.

5. Conversational ASO

Ask Play killed keyword ASO; semantic ASO is unbuilt.

6. Alt-billing rails

Post-Epic permits alt billing; no neutral dev-friendly layer that isn't RevenueCat (IAP) or Stripe (web).

7. Spark Action SDK

Canva, OpenTable, Instacart hand-onboarded. No SDK for indie devs to plug into Spark.

8. Eyewear-native apps

XR audio glasses ship Fall 2026 with thin 3rd-party story.

9. Agent traffic verification

WebMCP creates huge bot/human ambiguity. No Cloudflare-Bot-Mgmt equivalent for agents.

10. Long-tail consumer hw

Home/Buds/Watch/Nest skipped. Better hubs for stranded Nest devices = lane.

11. Non-Kotlin Android tooling

Migration Agent only migrates into Kotlin. RN/Flutter/KMP devs abandoned.

12. PWA / web-app discovery

Play Shorts + Ask Play centralize native; web apps got nothing.

For a developer-tools / app-distribution startup

Wedges Google left on the table

1. Semantic / conversational ASO

Ask Play is the consumer surface — nobody is selling Ask-Play-optimization-as-a-service. Build the LLM that reverse-engineers Ask Play signals + generates semantic descriptions + Play Shorts video creative.

2. Alt-store-in-a-box

Registered Stores is a gate, not a product. Ship the SDK + payments + integrity scaffolding so any publisher (game studio, media co) stands up a registered store in days.

3. Spark Action Marketplace

Neutral aggregator/registry for Spark + Apple App Intents + MS Copilot Actions. "Agent App Store."

4. Agent traffic verification on open web

WebMCP creates bot/human ambiguity. Cloudflare-Bot-Mgmt for agentic traffic.

5. Cross-platform app-dist analytics

Span Play Shorts views + Gemini app surfaces + Engage SDK opens + alt-store installs. Google won't unify this.

6. Vertical coding agents

Antigravity is enterprise-oriented. Cursor's "fast, opinionated, IDE-feel" wedge is still defensible; so are game-dev, embedded, and regulated-industry agents.

7. Privacy-first agentic tooling

For regulated industries (healthcare, legal, finance) that cannot route through Gemini Spark on Google VMs.

8. Eyewear-first developer SDKs

Android XR developer story for glasses is thin. Build the SDK.

For a developer-tools / app-distribution startup

Strategic recommendations

  1. Pick the post-keyword ASO wedge. Build LLMs that (a) reverse-engineer Ask Play's recommendation signals, (b) generate semantic descriptions + Q&A optimized for those signals, (c) generate Play Shorts–ready video creative. Wedge: "ASO is dead, semantic discovery is here." Moat: proprietary {query → app recommended} dataset.
  2. Don't fight Antigravity head-on. Position as either (a) the non-Google multi-model coding agent (Anthropic + OpenAI + Mistral routing) for teams that won't lock into Gemini, or (b) the vertical coding agent (games, embedded, regulated) Antigravity doesn't reach.
  3. Build a Spark Action SDK middleware. Write once, ship to Spark + Apple Intelligence + Copilot Actions. Bonus: usage analytics none of the platforms expose.
  4. Alt-billing & alt-store toolkit for post-Epic Android. External-link payments, registered-store onboarding, integrity attestation, fraud monitoring, regional pricing — one SDK.
  5. Avoid:
    • Generic "AI for developers" with no vertical/distribution wedge — Google + Cursor + Anthropic will out-spend you.
    • Building on Gemini CLI (sunset June 18) or Vertex AI branding (renamed).
    • Indie distribution plays in markets where Sept 2026 verification rolls out without a compliance story.
    • PWA / web-app stores — Google chose not to invest, signaling weak demand.
The one-paragraph reframe

The AI layer eats the app layer

On B2C, Spark + AI Mode + Information Agents + Apps-inside-Gemini-app collectively make the Gemini surface the new top-of-funnel — Play Store demotes itself in the process. On B2B, Antigravity + Managed Agents + Workspace Studio + Enterprise Agent Platform make Google the default agent infrastructure provider.

The four highest-leverage wedges

1. Spark Actions middleware (no SDK exists yet)
2. Semantic ASO for the post-keyword Ask Play world
3. Privacy-first agentic tooling for regulated sectors
4. Alt-billing + alt-store toolkit for post-Epic Android
