Deep Dive

Gemini Spark — the architecture is the news

What ships

  • Persistent compute per user — dedicated VM, not on-demand inference
  • Persistent context, persistent agent identity
  • Runs while phone is off — server-side execution
  • Recurring tasks + custom sub-agents
  • Hand-curated integrations: Canva, OpenTable, Instacart

What it signals

  • Ongoing infra cost per Ultra sub — only works if agent retention drives stickiness
  • $249 → $99 cut: either inference costs collapsed, or $249 was choking adoption
  • Prices ChatGPT Pro ($200) and Claude Max ($200) awkwardly
  • Server-side execution = no on-device privacy story
  • No public Action SDK for 3rd-party devs

Two white-space arrows for a startup

1. Privacy-first / on-device agent for regulated industries that can't route through Google VMs.
2. Spark Action SDK middleware — write once, ship to Spark + Apple Intelligence + Copilot Actions.

Opinionated assessment

White space — where Google is not investing

1. Privacy-first agents

Spark runs on Google VMs. No on-device story.

2. Voice for devs

Gmail Live got voice; Antigravity is text only.

3. Vertical app stores

No Play for kids/edu/health/enterprise-internal.

4. App-store-as-a-service

No itch.io-for-mobile for indies.

5. Conversational ASO

Ask Play killed keywords; semantic ASO unbuilt.

6. Alt-billing rails

Post-Epic permits alt billing; no neutral dev layer.

7. Spark Action SDK

Canva/OpenTable hand-onboarded. No public SDK.

8. Eyewear-native apps

XR ships Fall 2026 with thin 3rd-party story.

9. Agent traffic verification

WebMCP creates bot/human ambiguity. No solution.

10. Long-tail consumer hw

Home/Buds/Watch/Nest skipped at I/O.

11. Non-Kotlin tooling

Migration Agent only migrates INTO Kotlin.

12. PWA discovery

Play Shorts + Ask Play centralize native only.

For a developer-tools / app-distribution startup

Direct threats and wedges left on the table

Direct threats

  • Ask Play + Play Shorts displace keyword ASO (AppTweak, Sensor Tower, Data.ai)
  • Gemini in Play Console eats listings-optimization SaaS
  • Engage SDK in Gemini app — install-attribution measurement breaks
  • Agentic catalog mgmt eats SKU SaaS for IAP publishers
  • Billing 9 + Protected with Play squeezes anti-fraud SDKs (Promon, Approov)
  • Antigravity suite + AI Studio target Cursor, Devin, Replit, no-code mobile
  • Dev Verification (Sept 2026) raises alt-store baseline cost

Wedges Google left on the table

  • Semantic / conversational ASO — Ask-Play-optimization-as-a-service
  • Alt-store-in-a-box — SDK + payments + integrity for publishers
  • Spark Action Marketplace — neutral registry across Spark / Apple / Copilot
  • Agent traffic verification — Cloudflare-Bot-Mgmt for WebMCP
  • Cross-platform app-dist analytics — Play Shorts + Gemini + Engage + alt-stores
  • Vertical coding agents Antigravity won't reach (game-dev, embedded, regulated)
  • Privacy-first agentic tooling for sectors that can't route through Google VMs
  • Eyewear-first dev SDKs — XR developer story is thin
Recommendations + closing

The AI layer eats the app layer

On B2C, Spark + AI Mode + Info Agents + Apps-in-Gemini-app make the Gemini surface the new top-of-funnel — Play Store demotes itself. On B2B, Antigravity + Managed Agents + Workspace Studio + Enterprise Agent Platform make Google the default agent infra provider.

5 strategic moves

  1. Post-keyword ASO wedge — reverse-engineer Ask Play signals; gen semantic descriptions + Play Shorts creative. Moat: proprietary {query → app} dataset.
  2. Don't fight Antigravity head-on — go non-Google multi-model OR vertical (game, embedded, regulated).
  3. Spark Action SDK middleware — write once, ship to Spark + Apple + Copilot.
  4. Alt-billing + alt-store toolkit for post-Epic Android.
  5. Privacy-first agentic tooling for sectors that can't route through Google VMs.

Avoid

  • Generic "AI for developers" — Google + Cursor + Anthropic will out-spend you
  • Building on Gemini CLI (sunset June 18) or Vertex AI branding (renamed)
  • Indie distribution in Sept-2026-verification markets without a compliance story
  • PWA / web-app stores — Google chose not to invest
